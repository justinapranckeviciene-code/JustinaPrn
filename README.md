# mom_justina — TARO

**[ATIDARYTI SVETAINĘ](https://mom-justina-taro.vercel.app/)**

Vieša TARO svetainė: klausimas, trys ištrauktos kortos ir konkrečiam klausimui skirta AI interpretacija. Registracija neprivaloma.

Išsaugotas originalus dizainas, visos 78 Rider–Waite–Smith kortos, jų pozicijos ir tiesi bei apversta orientacija. Originalus GPT-6 Astra modelis, reasoning low, promptas ir atsakymo schema nepakeisti.

Atlikti 30 tikrų naujos versijos atsakymų bandymų ir sėkmingas viešos svetainės bandymas naršyklėje nuo klausimo iki interpretacijos. Ankstesnės ir naujos versijų porinis palyginimas neatliktas; savininkė aiškiai leido paleisti pagal kandidatės bandymus. Žr. [paleidimo leidimą](audit/LAUNCH-APPROVAL.md).

Savanoriškos paramos funkcija laukia savininkės paramos puslapio nuorodos.

## Vietinis kūrimas

```sh
npm ci
npm test
npm run typecheck
npm run dev
```

Slapti prisijungimo duomenys laikomi tik serverio aplinkoje, į Git jų įrašyti negalima.
